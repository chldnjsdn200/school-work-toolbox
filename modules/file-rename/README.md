# 파일명 일괄 변경기

여러 파일의 이름을 반복적으로 수정하는 업무를 브라우저에서 한 번에 처리하기 위한 독립형 모듈입니다. 원본 파일을 직접 바꾸지 않고, 변경된 이름으로 새 다운로드 파일을 만듭니다.

## 주요 기능

- 여러 파일 동시 선택
- 원본 파일명과 확장자 구분
- 접두어 추가
- 접미어 추가
- 특정 문자열 찾기 및 변경
- 특정 문자열 제거
- 전체 파일명을 동일한 형식으로 변경하고 번호 자동 부여
- 시작 번호와 번호 자릿수 설정
- 변경 전 미리보기
- 중복 파일명, 빈 파일명, Windows 금지문자 검사
- 선택 파일 초기화
- 이름 변경 옵션 초기화

## 파일 처리 방식

선택한 파일은 서버로 업로드되지 않습니다. 모든 처리는 현재 브라우저 내부에서 수행됩니다.

이 모듈은 실제 파일 내용을 분석하지 않고 파일 객체와 파일명만 사용합니다. 변경된 파일을 만들 때도 브라우저의 다운로드 기능을 이용해 원본 파일과 같은 내용의 파일을 새 이름으로 내려받습니다.

## 확장자 처리

확장자는 기본적으로 유지됩니다.

예를 들어 `IMG_001.jpg`에 접두어 `체육대회_`를 추가하면 `체육대회_IMG_001.jpg`가 됩니다.

## 지원 규칙

- 접두어 추가: `IMG_001.jpg` -> `체육대회_IMG_001.jpg`
- 접미어 추가: `IMG_001.jpg` -> `IMG_001_보관.jpg`
- 문자열 변경: `최종` -> `완료`
- 문자열 제거: `20260904_` 제거
- 번호 자동 부여: `체육대회_001.jpg`, `체육대회_002.jpg`

번호 자동 부여를 켜면 기존 파일명 대신 `공통 이름 + 번호 + 기존 확장자` 형식으로 새 이름을 만듭니다.

## 알려진 제한사항

- 브라우저 보안상 원본 파일명을 직접 바꾸지는 않습니다.
- 변경된 이름의 새 파일을 개별 다운로드하는 방식입니다.
- 여러 파일을 ZIP으로 묶는 기능은 외부 라이브러리 없이 구현 범위가 커서 v1에는 포함하지 않았습니다.
- 브라우저 설정에 따라 여러 파일 다운로드 허용 여부를 물어볼 수 있습니다.
- 파일 내용 분석, 이미지 EXIF 분석, PDF 내용 분석은 하지 않습니다.

## 개인정보 및 보안

- 선택한 파일은 외부 서버로 전송되지 않습니다.
- 모든 처리는 브라우저 내부에서 수행됩니다.
- 실제 학생 또는 교직원 개인정보 샘플을 포함하지 않습니다.
