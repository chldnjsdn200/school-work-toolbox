# 조건부 랜덤 모둠 편성기

교사가 설정한 조건을 반영해 학생 번호를 균등한 모둠으로 무작위 편성하는 독립형 모듈입니다. 학생 화면에서는 조건 내용을 보여주지 않고 일반 랜덤 모둠 편성처럼 보이도록 구성했습니다.

## 파일

- `index.html`: 학생용 실행 화면
- `teacher.html`: 교사용 설정 화면
- `grouping.css`: 공통 디자인
- `grouping-core.js`: 모둠 편성 계산 로직과 설정 저장/불러오기
- `grouping-student.js`: 학생 화면 버튼, 애니메이션, 결과 표시
- `grouping-teacher.js`: 교사 화면 설정 저장, 초기화, 요약 표시

## 화면

- 학생용 화면: `index.html`
- 교사용 화면: `teacher.html`

학생용 화면에는 교사용 조건, 조건 충족 시도 횟수, 내부 알고리즘 설명, 교사용 설정 버튼을 표시하지 않습니다.

교사용 화면은 주소창에 `teacher.html`을 직접 입력해서 접근합니다. 학생용 화면에서 `Ctrl + Shift + G`를 누르면 교사용 화면으로 이동할 수 있지만, 이 안내는 학생 화면에 표시하지 않습니다.

## 설정

설정은 서버 없이 브라우저의 `localStorage`에 저장됩니다. 저장된 설정이 없으면 학생 수 27명, 모둠 수 6개를 기본값으로 사용합니다.

```json
{
  "version": 1,
  "studentCount": 27,
  "groupCount": 6,
  "separatePairs": [[5, 12], [8, 20]],
  "togetherPairs": [[1, 9], [4, 15]],
  "fixedAssignments": [
    { "student": 2, "group": 1 },
    { "student": 7, "group": 3 }
  ]
}
```

학생 이름은 저장하지 않고 번호 기반 정보만 사용합니다.

## 지원 조건

- 같은 모둠 금지: `5-12`처럼 입력한 학생 쌍을 서로 다른 모둠에 배치합니다.
- 같은 모둠 우선: `1-9`처럼 입력한 학생 쌍을 같은 모둠에 배치합니다.
- 특정 모둠 고정: `2:1`처럼 입력하면 2번 학생을 1모둠에 고정합니다.
- 모둠별 인원 차이가 최대 1명 이내가 되도록 균등 분배합니다.

## 개인정보

- 모든 계산은 브라우저 내부에서 수행됩니다.
- 외부 API를 호출하지 않습니다.
- 서버로 데이터를 전송하지 않습니다.
- 실제 학생 개인정보 샘플을 사용하지 않습니다.

## 사용 방법

1. `teacher.html`에서 학생 수, 모둠 수, 필요한 조건을 번호 기준으로 입력합니다.
2. 설정을 저장합니다.
3. 학생 앞에서는 `index.html`을 열고 `모둠 만들기`를 실행합니다.
4. 필요하면 `다시 섞기`, `인쇄`, `결과 복사`를 사용합니다.
