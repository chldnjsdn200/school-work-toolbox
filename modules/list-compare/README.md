# 목록 비교기

두 개의 목록을 비교해서 공통값, A에만 있는 값, B에만 있는 값, 목록 내부 중복값을 빠르게 확인하는 데이터 업무경감 모듈입니다.

## 주요 용도

- 전체 대상 목록과 제출 완료 목록 비교
- 신청자와 참석자 비교
- 계정 생성 대상과 생성 완료 목록 비교
- 물품 지급 대상과 지급 완료 목록 비교
- 두 데이터 목록 간 누락/중복 확인

## 비교 방식

`A 목록 - 기준 목록`과 `B 목록 - 비교 목록`에 값을 입력한 뒤 `목록 비교하기`를 누릅니다. 기본 입력은 한 줄에 하나의 값이지만 줄바꿈, 쉼표, 세미콜론, 탭 구분도 지원합니다.

결과는 다음 항목으로 표시됩니다.

- 공통값
- A에만 있는 값
- B에만 있는 값
- A 내부 중복값
- B 내부 중복값

중복값은 `101 × 2`처럼 등장 횟수와 함께 표시합니다.

## 빠른 모드

- 일반 목록 비교
- 미제출자 찾기: A에 전체 대상, B에 제출 완료 목록을 넣으면 A에만 있는 값을 미제출로 표시합니다.
- 누락값 찾기: A 기준 목록에 있지만 B 확인 목록에 없는 값을 누락값으로 표시합니다.

## 전처리 옵션

기본값은 앞뒤 공백 제거 ON, 빈 줄 제거 ON, 대소문자 무시 ON, 비교 시 중복값 1개 처리 ON입니다.

고급 설정에서 다음 옵션을 변경할 수 있습니다.

- 앞뒤 공백 무시
- 빈 줄 제거
- 대소문자 무시
- 모든 공백 무시
- 숫자 형식으로 비교
- 비교 시 중복값은 1개 값으로 처리

기본적으로 `001`, `01`, `1`은 서로 다른 원본 값으로 유지합니다. `숫자 형식으로 비교`를 켜면 같은 숫자값으로 비교합니다.

## TXT/CSV 입력

A 목록과 B 목록 각각에 TXT/CSV 파일을 불러올 수 있습니다. FileReader API로 현재 브라우저에서만 파일을 읽으며 서버로 업로드하지 않습니다.

이번 버전의 CSV 입력은 한 열짜리 CSV 또는 쉼표로 단순 구분된 목록을 기준으로 합니다. 복잡한 다중 열 CSV 자동 해석과 `.xlsx` 입력은 지원하지 않습니다.

## 결과 저장

### CSV 저장

CSV는 외부 라이브러리 없이 생성합니다. UTF-8 BOM을 포함해 Windows Excel에서 한글이 깨질 가능성을 줄였습니다. 쉼표, 큰따옴표, 줄바꿈이 포함된 값은 CSV 규칙에 맞게 escape 처리합니다.

### Excel 저장

Excel `.xlsx` 저장은 SheetJS가 필요합니다. CDN이나 npm을 사용하지 않고 프로젝트 내부 공용 위치의 로컬 파일을 사용하도록 구성되어 있습니다.

```text
shared/libs/xlsx.full.min.js
```

현재 저장소에 해당 파일이 없으면 페이지는 멈추지 않으며, Excel 저장 시 `Excel 저장 기능을 불러오지 못했습니다. CSV 형식으로 저장해주세요.`라고 안내합니다. CSV 저장은 정상 동작합니다.

SheetJS 파일이 준비되면 결과 파일은 다음 시트로 구성됩니다.

- 요약
- 공통값
- A에만 있음
- B에만 있음
- A 중복
- B 중복

## 개인정보 및 보안

- 입력한 목록과 불러온 파일은 서버로 전송되지 않습니다.
- 모든 비교 작업은 현재 브라우저 내부에서 수행됩니다.
- 목록 데이터는 `localStorage`에 저장하지 않습니다.
- 실제 학생 또는 교직원 개인정보 샘플을 포함하지 않습니다.
- 개인정보가 포함된 자료는 학교의 개인정보 처리 기준에 따라 사용해야 합니다.

## 알려진 제한사항

- SheetJS 로컬 라이브러리가 없으면 Excel 저장은 사용할 수 없습니다.
- `.xlsx` 파일 입력은 지원하지 않습니다.
- 복잡한 다중 열 CSV 자동 해석은 v1 범위에 포함하지 않았습니다.
- 매우 큰 목록은 비교 자체는 빠르지만 화면에 많은 결과를 표시할 때 시간이 걸릴 수 있습니다.
