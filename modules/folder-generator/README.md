# 폴더 일괄 생성기

학급별, 학년별, 업무별, 차시별 등 반복적으로 만들어야 하는 여러 폴더를 브라우저에서 한 번에 생성하기 위한 독립형 모듈입니다.

## 주요 기능

- 단순 폴더 일괄 생성
- 번호 기반 자동 생성
- 계층형 폴더 생성
- 학교 업무용 빠른 템플릿
- 생성 전 미리보기
- 중복 폴더명, 빈 폴더명, Windows 금지문자, 예약 이름 검증
- 기존 폴더가 있으면 삭제하거나 덮어쓰지 않고 건너뛰기
- 초기화

## 생성 방식

### 단순 폴더 일괄 생성

줄바꿈 또는 쉼표로 폴더명을 입력합니다.

```text
1반
2반
3반
```

또는

```text
1반, 2반, 3반
```

### 번호 기반 자동 생성

기본 이름, 시작 번호, 끝 번호, 번호 위치, 접두어, 접미어, 번호 자릿수를 설정해 폴더명을 자동 생성합니다.

```text
01차시
02차시
03차시
```

### 계층형 폴더 생성

경로 형식으로 하위 폴더 구조를 입력합니다. `/`는 하위 폴더 구분자로 사용합니다.

```text
2026학년도/1학년/1반
2026학년도/1학년/2반
2026학년도/2학년/1반
```

## 빠른 템플릿

- 학급 폴더: `1반`부터 `N반`
- 학년 폴더: `1학년`, `2학년`, `3학년`
- 월별 폴더: `01월`부터 `12월`
- 차시 폴더: `01차시`부터 `N차시`
- 학급 업무 기본 구조: `학급/가정통신문`, `학급/상담`, `학급/체험학습`, `학급/생활지도`, `학급/학급행사`, `학급/기타`

템플릿을 선택한 뒤 입력값과 개수는 사용자가 수정할 수 있습니다.

## 실제 폴더 생성 방식

Chrome 또는 Edge 계열 브라우저에서 지원하는 File System Access API의 `showDirectoryPicker()`를 사용합니다.

1. 생성할 폴더 목록을 작성합니다.
2. 미리보기를 확인합니다.
3. `생성 위치 선택` 버튼을 누릅니다.
4. 사용자가 PC의 대상 폴더를 직접 선택하고 권한을 승인합니다.
5. `폴더 만들기` 버튼으로 해당 위치에 폴더를 생성합니다.

기존 폴더는 삭제하거나 덮어쓰지 않습니다. 같은 이름의 폴더가 이미 있으면 건너뛰고 결과에 표시합니다.

## 개인정보 및 보안

- 입력한 정보는 서버로 전송되지 않습니다.
- 모든 처리는 현재 브라우저 내부에서 수행됩니다.
- 폴더는 사용자가 직접 선택한 위치에만 생성됩니다.
- 외부 API를 호출하지 않습니다.

## 알려진 브라우저 제한사항

- 직접 폴더 생성은 File System Access API를 지원하는 Chrome/Edge 최신 버전을 권장합니다.
- Firefox, Safari, 일부 모바일 브라우저에서는 직접 폴더 생성 기능이 동작하지 않을 수 있습니다.
- 브라우저가 폴더 접근 권한을 거부하거나 사용자가 선택을 취소하면 폴더를 만들지 않습니다.
- 이번 버전에는 외부 라이브러리를 이용한 ZIP 생성 방식이 포함되어 있지 않습니다.
