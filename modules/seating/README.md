# 조건부 랜덤 자리배치기

GitHub Pages에 그대로 올릴 수 있는 독립형 모듈임

## 파일
- `index.html` : 화면
- `seating.css` : 디자인
- `seating-core.js` : 자리배치 계산 로직
- `seating-ui.js` : 화면/버튼 처리

## 현재 기능
- 학생 수 설정
- 가로/세로 좌석 수 설정
- 조건 안에서 무작위 자리배치
- 특정 학생 앞 2줄 우선 배치
- 특정 학생 쌍 인접 금지
- 다시 섞기
- 학생 화면
- 인쇄

## 사용
폴더의 `index.html`을 브라우저에서 열면 됨

GitHub Pages에 넣을 때는 폴더째 `tools/seating/` 등에 복사하면 됨
