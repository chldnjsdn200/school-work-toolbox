# 조건부 랜덤 자리배치기

GitHub Pages에 그대로 올릴 수 있는 독립형 자리배치 모듈입니다.

## 파일

- `index.html`: 학생용 실행 화면
- `teacher.html`: 교사용 설정 화면
- `seating.css`: 공통 디자인
- `seating-core.js`: 자리배치 계산 로직과 설정 저장/불러오기
- `seating-student.js`: 학생 화면 버튼, 애니메이션, 결과 표시
- `seating-teacher.js`: 교사 화면 설정 저장, 초기화, 요약 표시

## 현재 기능

- 학생용 화면과 교사용 설정 화면 분리
- 조건 안에서 무작위 자리배치
- 특정 학생 앞 2줄 우선 배치
- 특정 학생 쌍 인접 금지
- 학생 수 설정
- 가로/세로 좌석 수 설정
- 설정 저장 및 초기화
- 저장된 설정 요약 확인
- 학생 화면에서 1~2초 동안 숫자가 섞이는 애니메이션 표시
- 다시 섞기

## 화면

- 학생용 화면: `index.html`
- 교사용 설정 화면: `teacher.html`

학생용 화면에는 학생 수, 좌석 행/열, 앞자리 우선, 분리 조건 같은 교사용 설정 항목을 표시하지 않습니다. 학생 앞에서는 일반 랜덤 자리배치처럼 보이도록 구성합니다.

교사용 설정 화면은 주소창에 `teacher.html`을 직접 입력해서 접근합니다. 학생용 화면에 교사 설정 버튼은 표시하지 않습니다. 추가로 학생용 화면에서 `Ctrl + Shift + S` 단축키를 누르면 교사용 설정 화면으로 이동할 수 있습니다. 이 단축키 안내는 학생 화면에 표시하지 않습니다.

## 설정 저장

설정은 서버 없이 브라우저의 `localStorage`에 저장됩니다.

저장 데이터는 실제 학생 이름을 포함하지 않고 번호만 사용합니다.

```json
{
  "version": 1,
  "studentCount": 27,
  "cols": 6,
  "rows": 5,
  "frontPriority": [3, 7, 12],
  "separatePairs": [[5, 12], [8, 20]]
}
```

저장된 설정이 없으면 기본값으로 학생 수 27명, 가로 6칸, 세로 5칸을 사용합니다.

## 개인정보

- 모든 계산은 브라우저 내부에서 수행됩니다.
- 외부 API를 호출하지 않습니다.
- 서버로 데이터를 전송하지 않습니다.
- 실제 학생 개인정보 샘플을 사용하지 않습니다.

## 사용 방법

1. 교사용 설정이 필요하면 `teacher.html`을 브라우저에서 엽니다.
2. 학생 수, 좌석 수, 조건을 번호 기준으로 입력하고 설정을 저장합니다.
3. 학생 앞에서는 `index.html`을 열고 `자리 섞기`를 실행합니다.

GitHub Pages에 넣을 때는 폴더째 `tools/seating/` 등에 복사하면 됩니다.
